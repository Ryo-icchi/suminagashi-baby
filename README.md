# すみながし — 1歳から遊べる墨流しアプリ

日本の伝統技法「墨流し」をデジタル化した、1歳児向けのお絵かきアプリ（PWA）。
参考: https://suminagashi-fjdbyyqi.manus.space/

v4.0 で、1歳児向けアプリのベストプラクティス調査（発達心理・色彩知覚・人気乳幼児アプリの仕掛け。詳細は `IDEAS.md`）を全面反映した。

## 遊び方（子供向け＝説明不要）

| 操作 | 起きること |
|---|---|
| 画面をタッチ | 波紋がパッと広がり、色滴がぽちゃんと落ちてうねる（色ごとの楽器音＋水音） |
| 連続タップ | 音がだんだん高くなる（連打が「演奏」になる） |
| 手のひらでペタン | 特大の滴と低い「ぼちゃん」 |
| 指でなぞる | 墨が流れて模様がうねる。なぞる高さで旋律が変わる（上ほど高い音） |
| 画面のどこか | 金魚（緋鯉）が1匹、指を追って泳ぐ |
| 10〜15回タップ | ときどきサプライズ：桜吹雪が舞い落ちる／金魚がぱしゃっと跳ねる |
| 何もしない（12秒） | 自動演出が始まり、勝手に模様が生まれる |
| マルチタッチ | 何本指でもOK。すべて同時に反応する |

- 画面の上ほど高い音（ペンタトニック2オクターブ）。どう触っても不協和音にならない
- 色ごとに音色が違う: あか=たいこ / あお=チャイム / きいろ=もっきん / みどり=ふえ / だいだい=はじき / むらさき=すず
- 滴が増えすぎたら古いものから自動で消える（画面が詰まらない）

## 色（はなやか / しぶい）

乳児は低彩度色の知覚・選好が弱い（高彩度では大人と選好が一致する）という研究を踏まえ、
**既定は「はなやか」モード**: 伝統色の色相を保ったまま彩度を引き上げた6色
（朱→ビビッド朱赤・藍→コバルト・山吹→ビビッド黄・松葉→鮮緑・橙・菖蒲）。
黒は入れない（鮮色と混ざると濁って汚く見えるため。墨は「しぶい」モードにのみ存在）。
「おまかせ」は1滴ごとに色が変わる（にじいろ自動）。
親パネルから従来の渋い伝統色（しぶいモード）に切り替えられる。

## 親向けの操作

- **3本指で1.2秒ホールド** → 画面を洗い流してリセット（右下🌊と同じ）
- **🎨を2.5秒長押し** または **4本指で1.5秒ホールド** → おうちのかたメニュー
  - **いろあい**: はなやか / しぶい
  - **いろの よみあげ**: 滴を落とすと「あか」「あお」と音声で色名（コビューイング・語彙支援。既定OFF）
  - **ボタンかくし（こどもロック）**: 🎨🌊を非表示（誤タップで作品が消えない）。戻すには4本指ホールド
  - **おやすみタイマー**: 5分/10分。満了すると夕焼け→月の「きょうは おしまい」画面（解除は月を2秒長押し）
  - **かたむきで ながれる**: 端末を傾けると墨がゆっくり流れる（iOSは権限許可が必要）
  - **📷 ほぞん**: 今の模様をPNGで共有/保存（流す前の1枚に）

## 1歳児向けの安全設計

- ピンチズーム・スクロール・長押し選択・ダブルタップ拡大をすべて無効化
- フルスクリーン起動（ホーム画面追加時）でSafariのUIバーが出ない
- Wake Lock APIで遊んでいる間は画面が消灯しない
- オフライン動作（Service Workerキャッシュ）— 一度開けばネット不要
- 失敗が存在しない設計（どこを触っても壊れない・ペナルティ音なし）
- タップへの応答は即時（波紋リング <100ms）— 乳児の因果学習は1秒の遅延で損なわれる

> さらに堅牢にするなら iPad の**アクセスガイド**（設定 > アクセシビリティ）を併用すると、
> ホームバースワイプでのアプリ離脱も防げる。

## iPadへのインストール（PWA）

1. iPadのSafariでアプリのURLを開く
2. 共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから起動 → フルスクリーンで立ち上がる

## 開発

```bash
python3 gen_icons.py          # アイコンPNG生成（標準ライブラリのみ）
python3 -m http.server 8000   # ローカル確認（Service WorkerはlocalhostでOK）
bash verify.sh                # headless Chromeで視覚検証 + SUMIプローブ確認
```

### 構成

- `index.html` — アプリ本体（WebGL流体シミュ + 2D FXオーバーレイ・依存ライブラリなし・1ファイル完結）
- `manifest.webmanifest` / `sw.js` — PWA設定・オフラインキャッシュ
- `gen_icons.py` — アイコン生成スクリプト
- `IDEAS.md` — 1歳児向けベストプラクティス調査と改善アイデア（出典付き）

### 実装メモ

- 流体: stable fluids（半ラグランジュ移流 + 圧力投影 + 渦度強化）+ 墨の吸収モデル（paper × exp(-dye)）+ 和紙ノイズシェーダ
- FXオーバーレイ: タッチ透過の2D canvas に波紋リング・金魚・桜を描画。金魚が流体に触れるのはジャンプ着水の一瞬だけ（泳ぎの常時攪拌は墨が定着しなくなるため意図的に不採用・Ryo FB 2026-06-11）
- ⚠️ 墨の実効注入量は Ryo 実機FB×3 の調整済み領域。乗算係数・追加注入源・連続攪拌を足すと実質上書きになる（`inkBudgetCheck` が verify.sh で回帰検知）
- 音: Web Audio 合成のみ（ペンタトニック2オクターブ・色別音色・ノイズ→バンドパス降下の水音）
- 設定は `localStorage`（`sumi.settings`）に永続化
