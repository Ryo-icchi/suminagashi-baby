# すみながし — 1歳から遊べる墨流しアプリ

日本の伝統技法「墨流し」をデジタル化した、1歳児向けのお絵かきアプリ（PWA）。
参考: https://suminagashi-fjdbyyqi.manus.space/

## 遊び方（子供向け＝説明不要）

| 操作 | 起きること |
|---|---|
| 画面をタッチ | 同心円の墨滴がぽちゃんと落ちる（やさしい効果音付き） |
| 指でなぞる | 墨が流れて模様がうねる。ゆっくりなぞると小滴が点々と落ちる |
| 何もしない（12秒） | 自動演出が始まり、勝手に模様が生まれる |
| マルチタッチ | 何本指でもOK。すべて同時に反応する |

- ボタン・メニューは一切なし。どこを触っても壊れない
- 滴が増えすぎたら古いものから自動で消える（画面が詰まらない）

## 親向けの隠し操作

- **3本指で1.2秒ホールド** → 画面を洗い流してリセット

## 1歳児向けの安全設計

- ピンチズーム・スクロール・長押し選択・ダブルタップ拡大をすべて無効化
- フルスクリーン起動（ホーム画面追加時）でSafariのUIバーが出ない
- Wake Lock APIで遊んでいる間は画面が消灯しない
- オフライン動作（Service Workerキャッシュ）— 一度開けばネット不要

> さらに堅牢にするなら iPad の**アクセスガイド**（設定 > アクセシビリティ）を併用すると、
> ホームバースワイプでのアプリ離脱も防げる。

## iPadへのインストール（PWA）

1. iPadのSafariでアプリのURLを開く
2. 共有ボタン（□↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから起動 → フルスクリーンで立ち上がる

## 開発

```bash
python3 gen_icons.py          # アイコンPNG生成（標準ライブラリのみ）
python3 -m http.server 8000   # ローカル確認（Service WorkerはlocalhostでOK）
```

### 構成

- `index.html` — アプリ本体（Canvas 2D・依存ライブラリなし・1ファイル完結）
- `manifest.webmanifest` / `sw.js` — PWA設定・オフラインキャッシュ
- `gen_icons.py` — アイコン生成スクリプト

### マーブリングのアルゴリズム

"Mathematical Marbling" (Lu et al.) の閉曲面変形モデル:

- **滴を落とす**: 既存の全頂点を `P' = C + (P−C)·√(1 + r²/|P−C|²)` で外側へ押し出す
  （和紙色の滴を交互に落とすことで同心リングが生まれる）
- **なぞる**: 指の位置からの距離減衰 `f = z·λ/(λ+d)` で頂点を移動方向に引きずる
- 伸びた辺は中点挿入でリサンプリングし、輪郭の滑らかさを維持
